# موقع المهندس غيث

موقع عربي أولاً (RTL) لعرض الحلول البرمجية وبناء التطبيقات.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يظهر في الطرفية (عادةً `http://localhost:5173`).

## البناء للإنتاج

```bash
npm run build
npm run preview
```
